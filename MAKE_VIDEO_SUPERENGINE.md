## Philosophy

"Tell MAKE what you want. MAKE figures out how to create it."

The user should not need to understand models, providers, technical parameters, masks, tracking, keyframes, compositing, or prompt engineering unless they explicitly want advanced control.

## Core Principles

1. **Natural language first** — All primary workflows accept NL input
2. **Intelligent defaults** — Powerful defaults that require no configuration
3. **Progressive disclosure** — Advanced controls only when needed
4. **Failure transparency** — Never fake successful generation
5. **Modular architecture** — Every system is independently testable
6. **Real execution** — Prioritize real execution over documentation
